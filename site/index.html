Format
Not a platform. A file.

One YAML file. Personality, tokens, assets, guidelines. Version it, diff it, own it. No vendor lock-in.

# brandspec.yaml
meta:
  name: "Acme Corp"

core:
  essence: "Making the impossible satisfyingly simple"
  personality:
    - innovative
    - approachable

tokens:
  colors:
    primary:
      $value: "oklch(0.7 0.15 250)"
      $type: color

guidelines:
  logo-usage:
    rules:
      - description: "Minimum size 120px"
        severity: error

assets:
  - file: logo-primary.svg
    role: logo
    variant: primary
  - file: logo-inverse.svg
    role: logo
    variant: inverse
  - file: symbol.svg
    role: symbol
  - file: icon-favicon.ico
    role: favicon

AI Harness
Brand rules AI can read.

One command turns any AI into your brand consultant. Structured rules keep AI agents on-brand at scale. The harness, not the cage.

Consult

One command, any model. brandspec consult reads your brandspec.yaml and prints a system prompt — personality, voice, do/don't, colors, typography, logo system, guidelines. Paste it into Claude, GPT, Gemini, or any AI. Instant brand consultant.

# Turn any AI into your brand consultant
$ npx brandspec consult | pbcopy

# Output (system prompt):
# You are a brand consultant for Acme Corp.
# You evaluate business decisions, creative work,
# and communications against this brand's identity.
# ...
# ## Voice & Tone
# Tone: direct, helpful
# ## Do / Don't
# ## Visual Identity
# ## Guidelines
Rules

Machine-readable constraints. guidelines.rules gives AI agents structured rules with severity, criteria, and scope. They lint, generate, and enforce — within your brand.

guidelines:
  logo-usage:
    rules:
      - id: logo-min-size
        description: "Minimum 120px width on digital"
        severity: error
        applies_to: logo
        criteria:
          - "Digital: minimum 120px width"
          - "Print: minimum 25mm width"

  voice:
    rules:
      - id: voice-no-jargon
        description: "No technical jargon in user-facing copy"
        severity: warning
        applies_to: voice
        criteria:
          - "No HTTP status codes in messages"
          - "No internal system terminology"
Lint

AI checks assets and copy against severity: error rules before shipping.

Generate

AI reads criteria to stay within constraints while creating.

Enforce

CI pipelines fail on error, warn on warning, note on info.
